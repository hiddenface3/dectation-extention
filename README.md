# 🎙️ ChatGPT Dictation Automator

> Automate voice dictation globally across **ChatGPT**, **Grok**, **Google Gemini**, or **any webpage** using global keyboard shortcuts! 🚀

---

## ✨ Key Features

- 🎙️ **Global Keyboard Shortcut**: Start/Stop dictation from anywhere on your PC (`Ctrl + Shift + Z`).
- 🤖 **1-Click Auto-Repair**: Automatically detects & repairs microphone selectors if AI sites update their UI.
- 🎯 **Visual Element Picker**: Visually click on any mic button on screen to set custom targets.
- 🌐 **Multi-AI Support**: Works out-of-the-box on ChatGPT, Grok, Google Gemini, and generic web pages.
- 📋 **Auto-Copy & Paste**: Automatically copies dictated text to your clipboard.
- 🖥️ **Native Desktop Helper**: Includes optional native host script for system-wide desktop auto-paste.

---

## ⚡ Quick Installation Guide

1. 📥 **Download & Extract**:
   - Download `ChatGPT_Dictation_Automator_v4.0.zip`.
   - Unzip the archive to a folder on your computer.

2. ⚙️ **Enable Developer Mode**:
   - **Microsoft Edge**: Open `edge://extensions` and toggle **Developer mode** ON (top-right).
   - **Google Chrome**: Open `chrome://extensions` and toggle **Developer mode** ON (top-right).
   - **Brave Browser**: Open `brave://extensions` and toggle **Developer mode** ON (top-right).

3. 📂 **Load Unpacked Extension**:
   - Click the **Load unpacked** button (top-left).
   - Select the folder containing the extension files.
   - 🎉 Done! The extension icon 🎙️ will appear in your browser toolbar.

---

## ⌨️ How to Use

- 🎙️ **Trigger Dictation**: Press `Ctrl + Shift + Z` once to start listening, and press again to stop & copy.
- 🎯 **Select Target Service**: Click the extension popup to switch between ChatGPT, Grok, Gemini, or Active Tab.
- ⌨️ **Change Shortcut**: Visit `edge://extensions/shortcuts` or `chrome://extensions/shortcuts` to customize keys.

---

## 🔧 Troubleshooting & Page Repair

- 🤖 **Auto-Repair**: If an AI website updates its layout, open the extension popup and click **Auto-Repair Current Page**.
- 🎯 **Pick Mic Visually**: Click **Pick Mic Button Visually** in the popup, hover over the microphone button on the web page, and click it.
